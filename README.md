# Punya Mittal — Brutalist × Retro Portfolio

Interactive personal portfolio built with **Next.js**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **GSAP**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `src/data/portfolio.ts` for name, projects, skills, experience, and social links.

## Easter eggs

- **Konami Code** (↑↑↓↓←→←→BA) — Retro Mode + secret achievement
- **Double-click logo** — cycle color palettes
- **?** — keyboard shortcuts
- **Alt+R** — toggle Retro Mode
- **Hidden pixel** — bottom-right corner
- Terminal commands: `help`, `projects`, `contact`, `resume`, `social`, `theme`, `retro`
